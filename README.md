# Laafia

Offline-first referral and visit-planning app for Community Health Officers in Northern Ghana.
Built for the UNICEF StartUp Lab AI for Nurturing Care Hackathon, Tamale, October 2026.

- `apps/mobile` Expo app (CHO, volunteer and facility modes)
- `apps/api` Express backend
- `apps/web` Next.js facility inbox and supervisor dashboard
- `packages/core` rules engine, scorer, SMS codec, signing, shared types
- `model` ranking model training
- `docs/SPEC.md` technical specification
